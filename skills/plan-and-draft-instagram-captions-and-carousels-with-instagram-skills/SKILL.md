# Run Instagram caption and carousel drafting with Instagram Skills

Transform campaign notes into Instagram captions and slide-by-slide carousel drafts, then review factual claims, voice, media order, and an approval card.

## Prerequisites

SKILL.md-compatible agent (Claude Code, Codex, or explicit Markdown context loading); Git for clone setup; Python and repository dependencies only for optional integrations; optional Publora credentials and supplied media for publishing

## Installation

Install or set up from the source-backed instructions:

Claude Code: run /plugin marketplace add sergebulaev/instagram-skills, then /plugin install instagram-skills@instagram-skills. For another SKILL.md-compatible runtime, clone https://github.com/sergebulaev/instagram-skills.git and explicitly load SKILL.md plus the relevant skills/*/SKILL.md. Draft-only use needs no API keys. For optional Python integrations, create an isolated virtual environment in the cloned repository and run python -m pip install -r requirements.txt. Configure optional service credentials through the documented .env.example; publishing requires a connected Instagram Business or Creator account.
