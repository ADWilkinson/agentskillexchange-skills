# Run owned terminal coding-agent workflows with Zero

Use Zero to run local, scriptable coding-agent sessions with operator-controlled models, permissions, tools, skills, MCP servers, and durable transcripts.

## Prerequisites

Zero CLI, npm or a GitHub Release binary, a supported LLM provider credential or local model, Git, and a target repository

## Installation

Install or set up from the source-backed instructions:

Install with npm install -g @gitlawb/zero, then run zero for the TUI or zero exec "fix the failing test in ./pkg" for a scripted coding-agent run. Use zero setup, zero providers list, zero models list, and zero doctor to configure and verify providers.
