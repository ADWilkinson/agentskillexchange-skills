# Supervise and reconcile persistent coding-agent crews with Firstmate

Dispatch scoped coding tasks into isolated worktrees, supervise durable task events, and reconcile the same crew after a primary-session restart.

## Prerequisites

macOS or Linux; Git; authenticated GitHub CLI; tmux; a supported primary terminal harness such as Claude Code, Pi, Grok, Codex or OpenCode; selected worker harness credentials and upstream toolchain prerequisites.

## Installation

Install or set up from the source-backed instructions:

Review https://github.com/kunchenguid/firstmate/blob/bd866530a07b23b57d933c6a745a9c81a2a94931/README.md and https://github.com/kunchenguid/firstmate/blob/bd866530a07b23b57d933c6a745a9c81a2a94931/docs/tmux-backend.md. Install Git, GitHub CLI, tmux and the chosen harness through normal operator setup. Authenticate gh if needed. Run git clone https://github.com/kunchenguid/firstmate, then cd firstmate, tmux new -s firstmate, and launch a documented primary harness, for example claude. Follow the loaded supervisor contract, approve missing-tool installations, and select the repository, task briefs and project delivery mode. Keep this dedicated operational home for restart reconciliation. No installation or task dispatch was executed during intake.
