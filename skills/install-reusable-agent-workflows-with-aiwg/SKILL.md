# Install reusable agent workflows with AIWG

Use AIWG to install and verify reusable project context, specialist workflows, skills, rules, and MCP utilities across Claude Code, Codex, Copilot, Cursor, and other supported agent providers.

## Prerequisites

Node.js 20 or newer, aiwg CLI, a project workspace, and a supported AI provider such as Claude Code, Codex, Copilot, Cursor, OMP, or Pi

## Installation

Install or set up from the source-backed instructions:

Use the agent-led setup manifest at https://aiwg.io/setup.aiwg.yaml, or install manually with npm i -g aiwg, then run aiwg use all --provider from the target project directory and review the verification output.
